# `docs/knowledge/`

Read-only baseline material. Research, business plans, market notes, regulatory references, supplier shortlists, anything that informs the work but isn't itself a design or plan.

## What goes here

- Inherited research (`_inspiration/` subfolder for AI-generated baseline material from Cowork, GPT, etc.)
- Domain references (regulatory citations, dietary rules, competitor teardowns)
- Founder notes that pre-date any specific design

## What does NOT go here

- gstack design outputs → `docs/designs/`
- superpowers plans → `docs/plans/`
- Working memory / live state → `_context/memory/` (if the project uses Cowork carryover)
- Stale or superseded → `docs/archived/`

## Conventions

Subfolders allowed and encouraged for grouping (`knowledge/regulation/`, `knowledge/competitors/`, `knowledge/_inspiration/`). No date-prefix requirement — these are reference docs, not artifacts.

Edit casually only when the underlying fact changed (e.g. regulation update). For analysis/decisions, write a fresh artifact in `designs/` instead of mutating knowledge in place.
